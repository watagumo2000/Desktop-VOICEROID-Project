# [Desktop-VOICEROID-Project] 


## 概要
これは、任意のVOICEROIDが常にデスクトップに表示されるアプリケーションです。
将来的にデスクトップのあらゆる補助を行ってくれるようにしたいです。
## 現状の主な機能
* 開発中！
## これからの主に実装したい機能
*デスクトップ上に琴葉姉妹を表示させる

## 🛠️ ローカルでの起動方法 (開発者向け)

1.  **リポジトリをクローン**
    ```bash
    git clone [https://github.com/](https://github.com/)[あなたのGitHub-ID]/[リポジトリ名].git
    cd [リポジトリ名]
    ```

2.  **依存関係のインストール**
    ```bash
    npm install
    ```

3.  **アプリケーションの起動**
    ```bash
    npm start
    ```

## 📝 開発メモ (個人用)

### 1. 運用ルール (GitHub Flowベース)

* **`main` ブランチ**
    * 常に正常に動作する状態（＝リリース可能な状態）を保つ。
    * `main` への直接の `git push` は禁止する。（将来的にGitHubのブランチ保護ルールで設定する）
* **機能ブランチ (Feature Branch)**
    * 作業は必ず `main` からブランチを切って行う。
    * ブランチ名: `feat/...` (新機能), `fix/...` (バグ修正), `docs/...` (ドキュメント) など、何をしているか分かりやすくする。
* **マージ (Merge)**
    * 作業が完了したら、`main` に対してプルリクエスト (Pull Request) を作成する。
    * セルフレビュー（自分で最終確認）した後、`main` にマージする。

### 2. コミットメッセージのルール
以下の接頭辞をつけることを推奨する。

* `feat:` 新機能の追加
* `fix:` バグ修正
* `docs:` ドキュメント（READMEなど）の更新
* `refactor:` 動作は変えないコードの整理
* `chore:` ビルド設定や雑務 (例: .gitignoreの更新)
* `style:` フォーマッタの実行など（コードの動作に影響しないスタイル変更）
